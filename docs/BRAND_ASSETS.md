# Journal logo assets

The original hq monogram and wordmark are preserved. PNG files with white backgrounds are available at:

- `public/brand/The_Human_Question_Logo.png`: full monogram and journal name.
- `public/brand/The_Human_Question_Monogram.png`: the hq mark on its own.

These are browser-rasterised exports of the existing HTML/CSS typography, using the original dark green (#183e35) and rust (#bc4b31). The standalone monogram omits the separator line used alongside the journal name. The website continues to render the original code-native wordmark.
