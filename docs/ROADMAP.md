# Remaining launch work

The scope is a simple journal website, with submissions and peer review handled by email. The site provides journal information, author instructions, house-style resources, an archive and links to final article PDFs.

| Work | Completion evidence |
| --- | --- |
| Confirm the submission inbox | The editor supplies the address; receipt and reply tests succeed; public instructions use that exact address |
| Finalise journal information | The editor approves the scope, instructions, review policy, names, contact details and publication terms |
| Check the house style | The Word and PDF resources are reviewed and their download links work |
| Publish the first articles | Human review and revisions are complete; final PDFs, author approval, licences and accurate metadata are available |
| Connect the domain | The host validates the DNS configuration for `thehumanquestionjournal.com` |
| Check the live website | Pages, mobile layout, links and PDF downloads work at the deployed address |
| Keep recoverable copies | The source and public PDFs can rebuild the site; the editorial mailbox and attachments have a separate recovery method |

The current source contains no verified submission inbox or real accepted articles. Do not replace these gaps with invented examples presented as publications.

No author portal, database, online review platform or automated publishing service is required for this launch. GitHub is used to update the website's public content. Any later additions should follow a concrete editorial need.

ISSN assignment is a separate application process. A domain, repository or website does not itself confer an ISSN, indexing status or scholarly accreditation.
